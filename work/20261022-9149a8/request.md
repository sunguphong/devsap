# 전기일자 기준 자재수불부 조회(일별)_저장위치레벨포함

# 전기일자 기준 재고조회 ABAP 프로그램 개발 요청

## 환경
- SAP ECC 
- 언어: ABAP 7.5x 이상 문법 (인라인 선언, NEW/VALUE, Open SQL 신문법) 사용
- 프로그램명: [ZMMR0000], 개발 클래스: [ZMM], 트랜잭션: [ZMM0000]
- 화면: SALV(cl_salv_table) 사용

## 목적
사용자가 입력한 "기준 전기일자" 시점의 재고를 조회한다. (MB5B와 비슷한 개념)
1. 메인 화면: 플랜트 + 저장위치 단위 요약
2. 행 선택 후 [상세조회] → 팝업에 상세 목록 표시
   - 배치관리 자재: 자재코드 + 배치 단위
   - 배치관리 아닌 자재: 자재코드 단위

## 선택화면
- 기준 전기일자 (P_BUDAT, 필수, 기본값: 오늘)
- 플랜트 (S_WERKS, 필수)
- 저장위치 (S_LGORT)
- 자재코드 (S_MATNR)
- 자재유형 (S_MTART), 자재그룹 (S_MATKL)
- 배치 (S_CHARG)
- 체크박스: 재고 0인 행 제외 (기본 체크)
- 권한체크: 플랜트 기준 M_MSEG_WMB (ACTVT 03)

## 재고 산출 로직 (중요)
- S/4HANA는 MSEG/MKPF가 아니라 MATDOC 기반이므로 MATDOC 또는 CDS View로 계산한다.
- 1순위: CDS View I_MaterialStock (또는 I_MaterialStock_2)에서
  MatlDocLatestPostgDate <= P_BUDAT 조건으로 MatlWrhsStkQtyInMatlBaseUnit 합계
- 2순위(CDS를 쓸 수 없는 경우): MATDOC에서 BUDAT <= P_BUDAT 조건으로 수량 합계
  (차변/대변 부호는 SHKZG 기준 처리, 취소전표 이중 집계 주의)
- 재고유형 구분: 가용(Unrestricted) / 품질검사(QI) / 보류(Blocked) / 합계
- 특별재고(위탁, 프로젝트 등)는 [제외 / 별도 컬럼] 처리
- 위 로직의 결과가 MB5B(동일 조건, 저장위치 재고) 결과와 일치하는지 검증 방법도 같이 제시

## 배치관리 여부 판단
- MARC-XCHPF(플랜트 레벨) 기준으로 판단하고, 값이 없으면 MARA-XCHPF를 참고
- 배치관리 자재 → 자재 + 배치로 집계
- 비배치 자재 → 자재 단위로 집계 (배치 컬럼은 공란)

## 메인 ALV (플랜트 + 저장위치 단위)
컬럼: 플랜트, 플랜트명, 저장위치, 저장위치명, 자재 건수, 배치 건수,
      재고금액(기준일 시점, 통화) [필요 시]
- 단위가 서로 다른 자재 수량은 합산하지 않는다 (수량 합계 컬럼 없음)
- 툴바에 [상세조회] 버튼 추가, 더블클릭으로도 상세조회 가능
- 여러 행 선택 시 선택된 플랜트/저장위치 전체를 상세에 표시

## 상세 팝업 ALV
- cl_salv_table 팝업 (set_screen_popup) 사용, 크기는 화면의 약 80%
컬럼: 플랜트, 저장위치, 자재코드, 자재내역, 배치(배치관리 자재만),
      기본단위, 가용재고, 품질검사재고, 보류재고, 합계재고, [재고금액]
- 정렬: 자재코드 → 배치
- 팝업 안에서도 필터, 정렬, 엑셀 다운로드 가능

## 성능
- 대상 플랜트 기준으로 데이터를 한 번에 읽어 내부테이블에서 집계한다
  (LOOP 안 SELECT 금지)
- 상세는 메인에서 이미 읽은 데이터를 재사용한다 (팝업 열 때 DB를 다시 읽지 않음)
- 가능하면 집계(SUM, GROUP BY)를 DB에서 처리

## 코드 구조
- 로컬 클래스 기반: lcl_data(조회·집계), lcl_view(ALV·이벤트)
- INCLUDE 분리: TOP / SEL / C01 / F01
- 주요 로직에 한글 주석
- 텍스트 엘리먼트, 선택화면 텍스트, 메시지 클래스 생성 목록도 함께 제시

## 결과물
1. 전체 소스 코드
2. 생성해야 할 텍스트 엘리먼트 / 메시지 목록
3. MB5B와 결과를 비교하는 테스트 시나리오 (배치자재 1건, 비배치자재 1건, 기준일 이후 입출고가 있는 자재 1건)


재고금액은 빼줘
예를 들어     2026.10.21일 전기일 등록하고 조회하면 아래와 같은 정보가 나와야해
2026.10.21 기초재고
2026.10.21 입고
2026.10.21 출고
2026.10.21 기말재고
