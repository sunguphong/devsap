# 스크랩(SCRAP) 기본단가 관리 공문 메일발송 기능 개발

자세한 내용은 구글시트에 있으니 참고해줘

아래 내용은 정보처리의뢰서에 올라온 내용이야


지속적인 업무 협조에 항상 감사 드립니다.

  

 표제 건과 관련하여 아래와 같이 SAP 고철등급별 단가관리(ZEMM0020) 

 화면 내 공문 발송 기능 적용을 요청 드리오니, 검토 후 반영하여 주시기 바랍니다.

                                       

                                                   -       아               래       - 

 

  1. 요청 사항 : SAP_고철등급별 단가관리(ZEMM0020) 화면의 단가 정보를 

                           활용하여 스크랩 공급사 대상 공문을 메일 형식으로 작성.발송할 

                           수 있는 기능을 신규 적용 요청

 

  2. 요청 사유 

       1) 현행 업무 프로세스

          -  현재 스크랩 공급사에서 국내스크랩 기본단가 공문을 요청할 경우,

              Iris 결재작성의 대외공문 기능을 활용하여 공문을 작성.결재 후 발송하고 있음 

       2) 개선 필요성

          - SAP 시스템 내 단가 정보를 활용한 공문 발송 기능을 적용할 경우,

            공문 작성 및 발송에 소요되는 업무 처리시간을 단축하고 업무 효율성 향상 기대와

            수기 작성에 따른 입력 오류 및 휴먼에러를 예방하여 업무 정확성을 제고할 수 있음  - 끝 -
